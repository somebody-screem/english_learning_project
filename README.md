# Phrase

語句番号を並べ替えて英文を作る、ローカル英語学習アプリです。

## Windowsで利用する

1. 配布された `Phrase-0.1.0-Windows.exe` をPCに保存します。
2. ファイルをダブルクリックして起動します。
3. サンプルセットの「学習する」を選ぶか、自分の問題を作成・取り込みます。

Windows x64向けのインストール不要のポータブル版です。利用者がNode.jsなどの開発環境を入れる必要はありません。通常の学習にネット接続やアカウントは不要です。実行ファイルは未署名のため、Windowsのセキュリティ警告が表示される場合があります。macOS / Linux用の実行ファイルは提供していません。

ローカルでビルドしたファイルは `release/Phrase-0.1.0-Windows.exe` にあります。GitHubのソースコードZIPには実行ファイルは含まれません。リポジトリを公開するだけでは、利用者が実行ファイルをダウンロードできる状態にはなりません。

## できること

- 問題セット・セクション・問題の作成と編集。和訳・解説・タグ・別解・下書き。
- 語句番号をカンマまたは空白で入力。10以上の番号、全角数字にも対応。クリック追加・英文プレビューのドラッグ移動も可能。
- 即時採点とまとめて採点。回答・語句番号を保持した前後移動、学習の中断再開、初回正解数と履歴。
- 名前・説明の検索と独立した問題タグのAND/OR検索。
- フォルダ作成・名称変更・削除・複数セット移動。フォルダから既存セットをタグ検索して追加。
- 合成・抽出。セクション、問題タグ、個別選択。独立コピーを既定とし、共有参照も選択可能。
- CSV / XLSXのシート選択・列対応・行ごとの検証・取り込み前確認。
- 完全バックアップと復元。SQLiteの原子的置換、前回ファイルの保全。

### 学習

1. セットの「学習する」を選択します。
2. 採点モード・和訳・対象セクション／タグを選択します。
3. `3, 1, 2, 4` のように番号を入力します。`10` は番号10、`1112` は番号1112です。
4. 即時採点はEnterで採点、次のEnterで次問へ。一括採点はEnterで次問へ進み、最後に明示的に提出します。
5. 「保存して終了」で中断し、履歴または一覧のバナーから再開できます。

全語句を各1回使います。未回答は提出できますが、途中まで入力した回答は完成させるかクリアしてください。別解は登録されたものを採点します。不一致は英語として不自然だと断定するものではありません。

### 問題の編集

語句分割は**正解順で1行に1語句**を入力します。`look forward to` のような句も1行にできます。正解英文には末尾の `. ! ?` を付けられますが、それ以外の大文字・句読点は語句と一致させてください。

許容解答は編集画面の語句の行番号を空白で区切り、1行に1つ入力します。例えば `4 1 2 3`。不完全な問題も下書き保存できますが、学習から除外されます。Ctrl/Cmd+Sで保存できます。

共有問題は使用中のセット名を表示します。「コピーして編集」で他のセットから切り離せます。独立コピーを作った後の変更は元に反映されません。

### CSV / Excel

「取り込む」からテンプレートをダウンロードできます。UTF-8（BOM可）のCSV、`.xlsx` に対応します。`.xls`、`.xlsm` は対象外です。1ファイル10MB、1シート10,000問までです。

| 列 | 内容 |
| --- | --- |
| 正解英文 | 必須 |
| 語句分割 | `I / drink / coffee`。空欄なら単語分割 |
| 問題名・和訳・解説 | 任意の文字列 |
| セクション | セット内の章名 |
| タグ | カンマで区切る |
| 許容解答 | 1行に1つ、語句を `/` で区切って記入 |

CSVのカンマ・改行を含むセルは二重引用符で囲みます。Excel数式は実行せず保存済みの結果を読みます。問題のある行は行番号と理由を表示し、全件が正常になるまで作成しません。

## データ

デスクトップの保存先はElectronのユーザーデータ領域内の `phrase.sqlite`（通常 `%APPDATA%/phrase-desktop/`）です。`phrase.sqlite.previous` は直前の保存です。バックアップ機能からJSON形式で全データを持ち出せます。復元前には現在のデータもダウンロードします。

ブラウザプレビューはlocalStorageを使い、デスクトップとは別の保存先です。JSONバックアップで相互に移せます。編集中は保存ボタンで、学習中は移動・採点・終了時に保存します。

## 開発

Node.js **24以降**を推奨（配布ツールのため22.12以上が必要）。

```sh
npm ci --legacy-peer-deps
npm run dev          # http://127.0.0.1:5173
npm run build
npm test
npm run test:e2e     # Edgeを使用。デスクトップテストにはビルド成果物が必要
npm run desktop
npm run package
```

`npm run package` はWindows portableを生成します。`npm run format` でソースを整形します。依存パッケージのメジャー更新時は `npm audit` とCSV/XLSX・デスクトップのテストを再実行してください。

## 実行ファイルの作成と配布

Windows x64環境でNode.js 24以降を使い、次のコマンドを実行します。

```sh
npm ci --legacy-peer-deps
npm run package
```

成果物は `release/Phrase-0.1.0-Windows.exe` です。ビルド時には依存パッケージやElectronの取得にネット接続が必要になる場合があります。

`release/` はGit管理から除外しています。実行ファイルをソースと一緒にコミットせず、配布するときは [GitHub Releases](https://github.com/somebody-screem/english_learning_project/releases) のリリース添付ファイルとしてアップロードしてください。Releasesへのアップロードは、ローカルのビルドやGitのプッシュとは別の操作です。

配布前には別のWindows PCでも起動と保存を確認し、リリース説明に「Windows x64向け」「インストール不要」「未署名」「既知の制約」を記載してください。教材も渡したい場合はCSV／Excelを一緒に配布できます。各利用者の学習データは各自のPCに保存されます。

## 今回の位置づけと制約

動作する初版です。添付計画の全リリースゲートを満たした正式配布版とは区別します。

- Windowsの開発環境で検証。macOS / Linux、他のクリーンPCへの導入、署名・公証は未検証／未実施。
- DBは正規化された多数のテーブルではなく、SQLite内の版付きドキュメントとして保存します。外部キー制約の代わりに共通モデルの検証を使います。初期スキーマのみ対応。
- 一括採点では提出前に正解・解説を画面やアクセシブルな要素へ出しません。ただし問題編集用データと採点スナップショットはローカルの同じアプリプロセス内にあり、開発者ツールに対する秘匿境界ではありません。
- 大規模データの性能保証、実際の日本語IMEによるOS横断確認、故障・電源断の網羅試験は未実施。
- インポート用の `/` を語句の中に使う場合は、取り込み後に編集画面で修正してください。通常の編集画面は改行区切りなので `/` を含む語句を保存できます。
- 新しいDB版への移行、自動更新、クラウド同期、AI自由採点は含みません。

判断理由は `docs/decisions.md`、受け入れシナリオの対応は `docs/acceptance.md` を参照してください。
