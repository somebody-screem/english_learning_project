# 実装判断ログ — 2026-09-15

添付資料は製品仕様と計画の参考資料として利用した。資料末尾の「まずIssue/PRだけを作り承認までコードを書かない」は今回の直接依頼ではなく、GitHub操作・公開も依頼されていないため実施していない。以下はユーザー確定事項ではなく変更可能な開発上の暫定判断。

| 項目 | 今回の判断 | 理由・影響 |
| --- | --- | --- |
| OS | Windows x64を初版の作成対象 | 現在の作業環境で確認可能。macOSは対応済みとしない |
| デスクトップ | Electron + React + TypeScript + Vite | Rustが未導入。現在の環境で実行可能なデスクトップ成果物を作り、Web UIも再利用 |
| 保存 | SQL.jsのSQLite、版付きアプリドキュメント | 純JSでネイティブビルド不要。コピーDBで更新後、tempを同期してatomic rename。保存失敗時にメモリと元ファイルを保全 |
| データモデル | Question / Entry / Section / Folder / Sessionの分離 | Sectionはセット所有。タグは問題属性。全機能が同じデータを参照 |
| 問題版 | 編集でrevisionを増加、セッションはclone | 学習途中の編集による採点・番号変化を防止 |
| 複製 | 独立コピー既定、共有参照を選択可 | 共有問題には影響先を表示しコピーして編集を提供 |
| 下書き | 保存可、出題不可 | 未完成の編集を失わない |
| 番号入力 | 空白とカンマ混在可、NFKC + 読点正規化 | 先頭ゼロ・空トークン・範囲外・重複を拒否。末尾カンマは編集中のみ許容。IME入力値を書き換えない |
| 採点 | 語句ID配列を対応テキストへ解決して同一性照合 | 同じ綴りの語句を交換しても正解にする。表示用英文と判定順を分離 |
| 句読点 | 表示用英文の末尾記号のみ許容差 | 大文字や途中の句読点を無条件に削除しない |
| 一括採点 | 最後に明示的提出、空回答は不正解 | 途中回答は形式検証。提出前の正解・解説は描画しない |
| 合成・抽出 | 条件確定後の静的セット、ID重複を除去 | 同名英文は自動統合しない。セクションは元セット名を付けて区別 |
| フォルダ | 1階層、単一所属 | 削除時はセットを未分類へ移す。同名は許容、IDで区別 |
| タグ | 大文字小文字区別、完全一致名、前後空白削除 | 名前変更・同義語統合は別機能 |
| CSV/XLSX | UTF-8、シート単位、全行正常時に作成 | 読み込みだけでは永続データを変更しない。数式はキャッシュ値のみ |
| バックアップ | version=1のJSON、検証後置換 | 復元前JSONダウンロードとdesktop previousファイル |
| 配布 | unsigned portable exe | インストール不要。一般配布用の署名・公証は未実施 |
